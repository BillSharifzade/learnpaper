# Releasing LearnPaper

## Android

### Signing key

Release builds are signed with the upload key in `android/keystore/learnpaper-release.jks`; its passwords
are in `android/keystore.properties`. Both files are git-ignored. **Back them up somewhere safe (password
manager + offline copy).** If you publish on Google Play with Play App Signing, this is your *upload* key:
losing it means asking Google to reset it; without Play App Signing, losing it means you can never update
the app again.

`keystore.properties` format (paths are relative to `android/`):

```properties
storeFile=keystore/learnpaper-release.jks
storePassword=…
keyAlias=learnpaper
keyPassword=…
```

Without that file, `assembleRelease` still works but produces an unsigned APK.

### Build

```bash
python3 content/scripts/build.py              # words + images into the app assets
cd android
./gradlew :app:testDebugUnitTest :app:lint     # unit tests and lint
./gradlew :app:assembleRelease                 # app/build/outputs/apk/release/app-release.apk (sideload)
./gradlew :app:bundleRelease                   # app/build/outputs/bundle/release/app-release.aab (Play)
python3 tools/smoke.py --apk app/build/outputs/apk/release/app-release.apk   # on a booted emulator
```

The release build runs R8 (code shrinking and optimisation) and resource shrinking.

### Versioning

`versionCode` / `versionName` in `android/app/build.gradle.kts`. Bump `versionCode` for every upload.

### Store listing assets

- Icon: `branding/png/icon-512.png`
- Feature graphic (1024 × 500): `branding/png/feature-graphic.png` (generated by `branding/make_brand.py`)
- Screenshots: `python3 tools/smoke.py` saves onboarding, Today, Words, Settings and the home screen
- Short description (Tajik / Russian / English): the `app_tagline` strings
- Privacy: no account, no ads, no analytics; the only network use is the optional "check for new words"
  request to the pack manifest on GitHub.
