# LearnPaper brand

LearnPaper puts a new word on your phone's wallpaper every hour. The brand is warm paper, ink and two
cards: friendly for learners, calm enough to live on a lock screen all day.

## Mark

Two stacked flashcards; the front card carries a bold **ā**. The macron is how dictionaries mark
pronunciation, and it is what makes the Tajik letters **Ӣ** and **Ӯ** distinctive — the app is built for
Tajik, Russian and English speakers alike.

| File | Use |
|---|---|
| `logo.svg` | App icon master (rounded square, Iris gradient) |
| `logo-square.svg`, `logo-square-dark.svg` | Full-bleed icon for stores/iOS that apply their own mask |
| `mark.svg` | The two cards without background (in-app, splash, docs) |
| `wordmark.svg` | "Learn" in Ink + "Paper" in Iris, Onest ExtraBold |
| `lockup.svg` | Icon + wordmark, horizontal |
| `png/` | Exports: 512 px store icon, 1024 px iOS icon (light/dark), lockup, wordmark |

Everything is generated by `make_brand.py` from one geometry and the Onest glyph outlines, including the
Android adaptive icon (background, foreground and themed monochrome layers), the notification icon, the
in-app mark (`res/drawable/ic_brand_mark.xml`) and the iOS app icon set. Change the script, not the outputs:

```bash
python3 -m venv /tmp/brand-venv && /tmp/brand-venv/bin/pip install fonttools
/tmp/brand-venv/bin/python branding/make_brand.py      # needs rsvg-convert on PATH
```

Keep clear space around the mark of at least a quarter of its width; never recolour the cards individually
or put the mark on a busy photo.

CEFR levels have their own soft tints (A1 mint → C2 rose) so a level reads at a glance. Wallpaper cards use
the twelve palettes in `android/.../render/Palette.kt` (ten pastels and two dark ones: Midnight and Pine).

## Type

- **Onest** (SIL OFL) — the brand face for words, headings and interface text. Chosen because it covers
  Latin, Russian and every Tajik letter (Ғғ Ӣӣ Ққ Ӯӯ Ҳҳ Ҷҷ) with a modern, friendly and very legible design.
- **Inter** (SIL OFL) — for transcriptions only: it carries every IPA symbol and the macron/acute vowels of
  the Russian and Tajik transliterations.

Both are bundled as variable fonts (`android/app/src/main/assets/fonts/`) and used on both platforms, so
the wallpaper renders identically everywhere.

## Voice

Short, warm, direct. The interface is Tajik by default, with Russian and English one tap away; wallpaper
is "тасвири экран" in Tajik (as in GNOME's Tajik translation), never the Russian loan "обои".
